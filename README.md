# Employee Management System

## Project Description
This is a Spring Boot REST API project for employee management using JWT authentication.

## Features
- Employee registration
- Login authentication
- JWT token generation
- CRUD operations
- Pagination
- Sorting
- Validation
- Exception handling

## Technologies Used
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- Maven

## API Endpoints

### Auth APIs
POST /auth/register  
POST /auth/login  

### Employee APIs
POST /employees  
GET /employees  
GET /employees/{id}  
PUT /employees/{id}  
DELETE /employees/{id}  

## How to Run

Clone project:

```bash
git clone your-repository-link
```

Run project:

```bash
mvn spring-boot:run
```
